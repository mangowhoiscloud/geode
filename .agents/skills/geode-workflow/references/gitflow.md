# GitFlow

Use [geode-gitflow](../../geode-gitflow/SKILL.md) for authorized branch, PR,
merge, release, or cleanup operations. It owns the procedure; this reference
only routes to the relevant section.

| Task | Canonical section |
|---|---|
| Allocate or resume an owned checkout | [Worktree Allocation](../../geode-gitflow/SKILL.md#worktree-allocation) |
| Architecture claim or main-owned closure | [Architecture Ledger](../../geode-gitflow/SKILL.md#architecture-ledger) |
| Select local evidence | [Pre-PR Quality Gate](../../geode-gitflow/SKILL.md#pre-pr-quality-gate) |
| Write the PR | [PR Body Template](../../geode-gitflow/SKILL.md#pr-body-template) |
| Verify and merge the exact PR head | [Post-PR CI Ratchet](../../geode-gitflow/SKILL.md#post-pr-ci-ratchet) |
| Recover conflicts or missing CI events | [Concurrent-session drift](../../geode-gitflow/SKILL.md#concurrent-session-drift--ci-trigger-recovery) |
| Sync main before promotion | [Deliberate pre-sync](../../geode-gitflow/SKILL.md#deliberate-main-to-develop-pre-sync) |
| Prepare an authorized release | [Release Flow](../../geode-gitflow/SKILL.md#release-flow) |
| Free merged, no-longer-needed resources | [Post-Merge Cleanup](../../geode-gitflow/SKILL.md#post-merge-cleanup) |
| Install or restart when requested | [Rebuild & Restart](../../geode-gitflow/SKILL.md#rebuild--restart) |
